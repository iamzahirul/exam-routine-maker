# পরীক্ষার রুটিন মেকার 📝

> মিনিটেই পরীক্ষার রুটিন বানান — বিষয়, তারিখ, সময় দিন; সুন্দর টেবিল পাবেন। **প্রিন্ট করুন**, বা **টেক্সট কপি** করে হোয়াটসঅ্যাপে শেয়ার করুন। সম্পূর্ণ অফলাইন।

## ✨ Features

- ✅ **ডাইনামিক ফর্ম** — যত খুশি বিষয় যোগ/মুছুন (বিষয়, তারিখ, সময়, ঘর/কেন্দ্র)
- ✅ অটো **তারিখ অনুযায়ী সাজানো** টেবিল
- ✅ 📢 **আজ পরীক্ষা থাকলে ব্যানার** + "আজ!" হাইলাইট
- ✅ ⏳ প্রতিটি পরীক্ষায় **"কত দিন বাকি"** চিপ, হয়ে যাওয়াগুলো ডিম
- ✅ 🖨 **প্রিন্ট/পিডিএফ** — প্রিন্টে সুন্দর সাদা-কালো টেবিল
- ✅ 📋 **শেয়ার টেক্সট কপি** — বাংলা ডিজিটে ফরম্যাটেড, সরাসরি মেসেজে পেস্ট করুন
- ✅ রুটিন **লোকালস্টোরেজে সেভ** — পেজ রিফ্রেশ করলেও থাকে
- ✅ এক ক্লিকে উদাহরণ রুটিন লোড
- ✅ 100% অফলাইন — একটি মাত্র `index.html`

## 🧪 টেস্ট স্কোর

|---|---|
